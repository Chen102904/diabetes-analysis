## 3. 结局变量核查

数据里有两列长得都像结局，必须查清哪个才是。

```
dm_censor         0     1
dm_incident              
-1           207659  2870
 1                0  1304
```

- `dm_incident` 只有 **1,304** 行非空（0.6%），而 `dm_censor=1` 有 **4,174** 人
- 也就是说 `dm_incident` 只标出了 31% 的发病者，其余 69% 的发病者在这一列是空的
- **结论：`dm_incident` 是原始录入的中间标记，不能当结局。统一用 `dm_censor`（发病 4,174 人，1.97%）+ `followup_years`。**

结局是怎么判定的？看 `fpg_last`（末次随访空腹血糖）：

- 发病者中 `fpg_last >= 7.0`：**3,404** 人
- 发病者中 `fpg_last < 7.0`：**751** 人（中位 6.0）—— 这批人是通过**自报已确诊**或其他途径判定的
- **结论：结局 = FPG≥7.0 或 自报医生诊断，不是单纯靠血糖。**写论文/报告时必须这么写，否则别人复现不出来。

## 5. 入排标准的隐藏事实

- 基线 `fpg` 最小值 0.59、**最大值 6.99**
- 基线 FPG≥7.0 的人：**0 个**
- **结论：原始研究已经剔除了基线糖尿病患者（FPG≥7.0 或已确诊），我们拿到的是「基线无糖尿病的封闭队列」。这是好事——不用自己写排除逻辑，但必须知道 `fpg` 在 7.0 处被截断了，不能拿它做「血糖连续值与风险」的曲线。**

- 但糖尿病前期（5.6≤FPG<7.0）仍有 **26,247 人（12.4%）**，他们的发病率是 **11.03%**，而血糖正常组只有 **0.69%**（差 16 倍）
- 处理：主分析保留（真实世界就该有这些人），敏感性分析里排除，看结论是否变化

| 变量 | 缺失率 |
|---|---|
| `height` | 0.0% |
| `sbp` | 0.0% |

| `tc` | 2.3% |
| `tg` | 2.3% |

| `alt` | 0.8% |

**关键问题：缺失是随机的吗？按站点拆开看 `smoking` 的缺失率：**


- `smoking` 的缺失率在各站点间从 **4.3%** 到 **98.9%**
- 这不是随机缺失，而是**「某些站点根本没做这项问卷」**——属于结构性缺失
- 佐证：有 `hdl` 的人平均 44.1 岁，没有的人 39.7 岁，说明缺失与人群构成相关（至少是 MAR，甚至 MNAR）

**所以：绝对不能 `dropna()`。** 直接把含缺失的行删掉，会一次性砍掉 71.6% 的样本，而且砍掉的是特定站点的人——相当于把一部分城市从研究里抹掉，结论直接偏掉。

正确的三条路（第 3 步再选）：
1. **主分析不放这个变量**（用不受缺失影响的变量建核心模型）
2. **把「缺失」当成一个单独类别**（`smoking_unknown`），而不是硬填
3. **多重插补**（MICE），并在第 7 步做「插补前后结论是否一致」的敏感性分析

## 7. 数据结构特征

- 站点 15 个，样本量从 61 到 51,190
- 随访时间 2.00 – 7.56 年，中位 2.99 年
- 累计 661,468 人年
- 粗发病率 **6.31 / 1000 人年**（原论文年龄调整后为 7.35）

**按随访时长分层看发病率：**

```
                    n   inc  rate_%
followup_years                     
(1.9, 2.5]      70756  1048    1.48
(2.5, 3.0]      37063   716    1.93
(3.0, 3.5]      32871   527    1.60
(3.5, 4.0]      26401   743    2.81
(4.0, 5.0]      35830   894    2.50
(5.0, 8.0]       8912   246    2.76
```

- 注意发病率**不随随访时长单调上升**（2.5–3 年是 1.93%，3–3.5 年反而 1.60%）
- 原因：随访时长 = 末次体检年份 − 基线年份，它同时编码了**入组年份**。不同年份入组的人本身风险就不同（日历效应）
- **这直接决定了第 4 步怎么算发病率：不能用「发病人数/总人数」这种粗率，必须用人年（每 1000 人年）或生存分析。**

## 8. 审计结论：进第 2 步前必须先定下的 4 件事

| # | 决定 | 依据 |
|---|---|---|
| 1 | 结局 = `dm_censor`，时间 = `followup_years` | `dm_incident` 只标了 31% 的发病者 |
| 2 | 主分析不用 `smoking`/`drinking`/`ast`/`hdl`/`ldl` 建核心模型 | 站点级结构性缺失 45%–72% |
| 3 | 发病率用人年，不用粗率 | 随访时长混杂入组年份，出现日历效应 |
| 4 | 模型必须调整 `site` | 站点发病率 0–2.58%，差异远超随机波动 |
