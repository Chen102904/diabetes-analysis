## 一、字段分级（谁离识别个人最近）

| 字段 | 级别 | 判断依据 |
|---|---|---|
| `Pregnancies` | 准标识符 | 生育史，在女性人群中是强识别特征 |
| `Glucose` | 临床指标 | 检查数值，不直接识别身份 |
| `BloodPressure` | 临床指标 | 检查数值，不直接识别身份 |
| `SkinThickness` | 临床指标 | 检查数值，不直接识别身份 |
| `Insulin` | 临床指标 | 检查数值，不直接识别身份 |
| `BMI` | 临床指标 | 由身高体重算出，不直接识别身份 |
| `DiabetesPedigreeFunction` | 临床指标 | 家族史衍生指标，不直接识别身份 |
| `Age` | 准标识符 | 与妊娠次数、生育史组合后可缩小到个别人 |
| `Outcome` | 敏感属性 | 要分析的目标，泄露后果严重 |

## 二、重识别风险：k-匿名测算

- 准标识符：**Pregnancies + Age**
- 目标：任意组合下至少 **5 条**记录（k < 5 视为可定位）

| 等级 | 年龄处理 | 妊娠次数处理 | 最小组大小 k | 风险组数 | 总组数 |
|---|---|---|---|---|---|
| L0 | 原始值 | 原始值 | 1 | 254 | 292 |
| L1 | 5 岁一段 | 0 / 1-2 / 3-4 / 5+ | 1 | 12 | 33 |
| L2 | 10 岁一段 | 0 / 1-2 / 3-5 / 6+ | 1 | 3 | 18 |
| L3 | 20 岁一段 | 0 / 1-5 / 6+ | 1 | 1 | 7 |

⚠️ 即使最强泛化（L3 年龄 20 岁一段）k 仍为 1；此时应**抑制**落在小组合里的 **1 条记录**（不删除原始库，仅在外发版本里剔除）才能达标。

## 三、外发前检查清单

1. 直接标识符（姓名 / 身份证 / 手机号 / 医保号 / 住址）是否已删除或不可逆加密
2. 准标识符组合后的 k 值是否 ≥ 5
3. 敏感属性（诊断 / 用药）是否为必要最小范围
4. 是否取得患者或监护人知情同意，或具备法律豁免
5. 传输是否加密、落地后是否有访问控制与审计日志
6. 外发与脱敏操作是否已留痕（谁、何时、给了谁）
